## Defects found by the new tests and fixed

| Defect | Fix |
|---|---|
| `quad(1,1E10,1)` returned 0 for the small root (also `quad(1E-40,1,1)`) | small root now taken from x1 x2 = c/a when b^2 >> 4ac |
| Complex pair order depended on the sign of a | positive imaginary part always first |
| `-2147483648` could not be entered in decimal base-n | accepted as the 32-bit minimum |
| Vector angle of a zero vector returned a number | Math ERROR |
| Correlation `r` for constant y returned a number | Math ERROR |
| Uninitialised output and bad underflow handling in numeric integration (valgrind) | outputs initialised; only fatal statuses recorded |
| Parser stack frame grew when the minimum-integer helper was inlined | helper forced out of line; worst stack back to 10,692 B |
