## How many functions does the SC991 have?

The repository contains no definition of the advertised **417** target (`grep 417` finds only unrelated constants). 417 is Casio's own marketing figure for the fx-991ES PLUS (the fx-991EX is 552), and Casio does not publish how it counts. The table below counts what is actually reachable on the SC991 under an explicit, reproducible rule: every distinct key function, menu item, constant, conversion and statistic variable.

| Counted item | Count |
|---|---:|
| Distinct token-level functions reachable from keys or menus (operators, functions, structures, atoms) | 109 |
| Key actions that are not tokens (SHIFT, ALPHA, cursor, menus, variables, SD, ENG, M+, ...) | 36 |
| Menu actions (settings, data editor, linear-system grids, reset, clear) | 25 |
| Scientific constants | 40 |
| Unit conversions (directional entries; 20 pairs) | 40 |
| Statistical variables and regression coefficients | 26 |
| Regression types + 1-variable mode | 8 |
| Digits 0-9 and decimal point | 11 |
| **Total (SC991, this rule)** | **295** |

Variables A-F, X, Y, M are included in the key-action row. Digits are included. The total is **not** comparable with 417 because Casio's counting rule is unknown; it must not be used in advertising as 'N functions'. Recommendation: market the capability list (the register below), not a number, or publish our own counting rule with the number.

Catalogue coverage check: 119 lexer names, 0 not covered by a catalogue row.
